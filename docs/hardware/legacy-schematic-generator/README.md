# Legacy Schematic Generator (Archived)

This folder holds the previous SKiDL/ASG-based schematic generation
approach: `generate_schematic.py`, its rule set, ASG planning metadata, and
its last run's ERC/log output. It is kept for reference only.

Schematic generation and modification for this project now goes through the
`schematic-design` MCP skill (`.agents/skills/schematic-design/SKILL.md`),
backed by the `mcp-server-kicad` MCP server. Do not run the scripts in this
folder or follow their rules for new work; use the skill instead.
